## DESCRIPTION:

An Autonomous (this is still a WIP) AI agent that can be your actual assistant instead of completly replacing your human habilities. Inspired by the caracter "[J.A.R.V.I.S](https://en.wikipedia.org/wiki/J.A.R.V.I.S.)"

## How to install the source code:

1. Make sure you have Ollama installed, and install a model with tools supported

2. Install these packages

```

pip install ollama pyfiglet plyer pyttsx3

```

After that, you can run on your terminal:

```

git clone https://github.com/dyingtrojan/supino.git

```
